pyKnit in the browser

A proof-of-concept page running pyknit via PyScript. Chart rendering prefers an SVG backend when available, otherwise Pillow; if neither works the page degrades to a plain-text grid instead of crashing.

packages = ["pydantic", "pyknit"]

Gauge conversion

Convert a measurement from the pattern gauge (27.5 st / 10 in) to your own gauge (23.5 st / 10 in).

Chart rendering

Parse a tiny lace pattern and render it. Pillow/PNG output is shown as a base64 image; if rendering fails you get the parsed grid as text.

Serve this directory with any static file server (e.g. python -m http.server) and open demo.html.
